## 📖 About the Project

**Online Pet Shop Management** is a Software Requirements Engineering (SRE) project that models and plans a complete online pet shop platform. Rather than implementing code, this project focuses on the **requirements gathering, documentation, and agile project planning** phases of the software development lifecycle (SDLC).

The project uses **Jira** to manage the product backlog, user stories, and sprint planning — simulating a real-world agile development environment for a pet shop system.

## 📋 Jira Backlog Overview

The Jira backlog covers the complete feature set of the Online Pet Shop system, organized into **Epics, User Stories, and Tasks**:

### 🐾 Core Epics

| Epic | Description |
|------|-------------|
| User Management | Customer registration, login, profile management |
| Pet Catalog | Browse pets by type, breed, age, availability |
| Product Store | Pet food, accessories, and supplies listing |
| Cart & Orders | Add to cart, checkout, order placement & tracking |
| Vet Appointments | Schedule and manage veterinary appointments |
| Admin Panel | Manage pets, products, users, and orders |
| Notifications | Order confirmations, appointment reminders |

### 📌 Sample User Stories

- *As a customer, I want to browse available pets by category so that I can find a pet that suits me.*
- *As a customer, I want to add items to a cart and place an order so that I can purchase pet products online.*
- *As an admin, I want to manage pet listings so that the catalog stays up to date.*
- *As a customer, I want to book a vet appointment so that I can get timely care for my pet.*

## 📄 System Requirements

### ✅ Functional Requirements

- User registration, login, and profile management
- Pet catalog browsing with filters (type, breed, age, price)
- Shopping cart and order management
- Vet appointment scheduling
- Admin dashboard for full system control
- Order history and status tracking

### 🔒 Non-Functional Requirements

- **Security:** Encrypted passwords, session management
- **Performance:** Pages load within 3 seconds
- **Usability:** Mobile-responsive, intuitive UI
- **Reliability:** 99% uptime, data backup
- **Scalability:** Supports growing product catalog and user base

## 🔄 Agile Methodology

This project follows **Scrum** agile methodology:

```
Product Backlog Creation
        ↓
Sprint Planning (User Stories → Sprint Backlog)
        ↓
Sprint Execution (Development Tasks)
        ↓
Sprint Review & Retrospective
        ↓
Release
```

| Artefact | Tool Used |
|----------|-----------|
| Product Backlog | Jira |
| User Stories | Jira Issues |
| Sprint Planning | Jira Sprints |
| Requirements Document | SRE Assignment PDF |
